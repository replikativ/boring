# Jolt byte-array codec

Require `[boring.core :as b]` from the ordinary `org.replikativ/boring` Maven dependency. On Jolt, `encode`, `encode-indexed` and `decode` support nil, booleans, signed 64-bit integers, text, keywords, millisecond dates, vectors, finite seqs, ordinary maps, records and registered application types. Text references and sealed indexes use the JVM wire layout. Map iteration order affects the bytes.

Use `tag-registry`, `register-record`, `register-records` and `register-tag` to install constructors or value conversions with the `:registry` option. Unknown records and custom tags retain their wire identity for supported payloads. Both writers accept `:stringref` and `:seqs`. By default lists and lazy seqs round-trip as seqs, including the empty list. With `:seqs false` they decode as vectors. Indexed writes also accept `:index` and `:index-min`. The decoder reads indexed values sequentially. Metadata preservation, random-access navigation, mmap, and additional Boring profiles are outside the Jolt API.

Run `test-jolt/check.sh` with a JDK, Clojure CLI and unzip. On x86-64 Linux it downloads the pinned stock Jolt release and checks its digest. Set `JOLT` to an absolute executable path to use an installed runtime. The script stages the built jar and its embedded POM in a temporary Maven repository, then compares Jolt output against JVM fixtures from a consumer with only test code on its source path.
