# Jolt byte-array codec

Require `[boring.core :as b]` from the ordinary `org.replikativ/boring` Maven dependency. On Jolt, `encode`, `encode-indexed` and `decode` support nil, booleans, signed 64-bit integers, text, byte strings, keywords, symbols, UUIDs, hash sets, millisecond dates, vectors, finite seqs, ordinary maps, records and registered application types. Text references and sealed indexes use the JVM wire layout. Map and set iteration order affects the bytes.

Use `tag-registry`, `register-record`, `register-records` and `register-tag` to install constructors or value conversions with the `:registry` option. Unknown records and custom tags retain their wire identity for supported payloads. Both writers accept `:stringref` and `:seqs`. By default lists and lazy seqs round-trip as seqs, including the empty list. With `:seqs false` they decode as vectors. Indexed writes also accept `:index` and `:index-min`. The decoder reads indexed values sequentially. Both writers preserve metadata by default and accept `:incl-metadata? false`. For deterministic wire formats, `encode` supports `:profile :canonical` on untagged nil, booleans, signed 64-bit integers, text, bytes, arrays (vectors or finite seqs) and ordinary maps of these values. Map keys are ordered by their unsigned encoded bytes. Tagged values, floats and metadata-bearing values with metadata enabled are outside this canonical subset. Both canonical encoding and decoding accept `:max-depth` from 1 to 128. Decoding also accepts `:max-items` (zero means unlimited), `:tolerate-unknown-tags`, and `:on-unknown-record` (`:fallback` or `:error`). Random-access navigation and mmap are outside the Jolt API.

Run `test-jolt/check.sh` with a JDK, Clojure CLI and unzip. On x86-64 Linux it downloads the pinned stock Jolt release and checks its digest. Set `JOLT` to an absolute executable path to use an installed runtime. The script stages the built jar and its embedded POM in a temporary Maven repository, then compares Jolt output against JVM fixtures from a consumer with only test code on its source path.
