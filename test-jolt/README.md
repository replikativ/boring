The Jolt entry point in this branch is `boring.core` from the ordinary jar. It supports `encode`, `decode` and `encode-indexed` for nil, booleans, signed 64-bit integers, text, keywords, millisecond dates, vectors and ordinary maps of those values. Text string references and sealed indexes use the JVM wire layout. The encoder accepts `:stringref`, plus `:index` and `:index-min` for indexed writes. Map iteration order affects the bytes. The decoder reads indexed values sequentially. Random-access navigation, mmap, custom tags, records and additional Boring profiles are outside this implementation.

Run `test-jolt/check.sh` with the Clojure CLI, a JDK and Jolt on PATH. Each fixture is written by the JVM and checked on Jolt through the public functions. The test does not depend on Konserve.
